# Machine Learning Fundamentals
## Project Overview
Этот проект был выполнен в рамках университетского задания для изучения и практического применения базовых алгоритмов машинного обучения с использованием Python.

Основная цель - научиться подготавливать данные, обучать модели машинного обучения и оценивать их результаты.

## Tools & Libraries

- Python
- pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## What I Practiced

**1. K-Nearest Neighbors (KNN)**
- Применение алгоритма классификации.
- Разделение данных на обучающую и тестовую выборки.
- Оценка модели с помощью Accuracy.

**2. Linear Regression**
- Обучение модели линейной регрессии.
- Прогнозирование числовых значений.
- Оценка результатов с помощью Mean Squared Error (MSE).

**3. K-Means Clustering**
- Применение алгоритма кластеризации.
- Разделение данных на группы по сходству признаков.
- Анализ полученных кластеров.

## Dataset
В проекте используется небольшой учебный датасет `dataset.csv`, содержащий 30 записей.

## Note

Это учебный проект, основная цель которого — практическое знакомство с алгоритмами машинного обучения, а не разработка готовой модели для реального использования.
